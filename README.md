# Folha de pagamento

Projeto da Prova A2 de Desenvolvimento de Software Visual, feito por `Marcos Jose Ferrari` e `Felipe Kadanos`.

API em .NET 8 com Entity Framework e SQLite para cadastrar, listar, buscar e remover folhas de pagamento e consultar o total dos salários líquidos.

Execute na pasta MarcosFerrari: `dotnet run --project FelipeKadanos --no-launch-profile --urls http://localhost:5000`.
